This project was created during a **1-hour UI Design Challenge** at an **intra-college hackathon**.

🥇 **Won 1st Place**

The challenge was focused on designing an impressive and functional user interface within a very limited timeframe.

One of the main highlights of the project is the **animated login page**, featuring playful custom character animations and a unique visual experience.

---

## ✨ Overview

**TutorPortal** is a classroom management dashboard designed for tutors to easily manage and monitor student information.

The interface provides a clean overview of:

- 👨‍🎓 Student records
- 📊 Attendance percentages
- 🎓 Academic grades
- 📞 Parent contact details
- 🚨 Students needing attention
- 📝 Student notes and observations
- ✏️ Editing student information

The goal was to combine a professional dashboard experience with a fun and memorable animated login screen.

## 🌟 Key Highlight — Animated Login UI

The biggest highlight of this project is the **animated login interface**.

Instead of using a traditional static login page, I designed a playful scene with custom characters and animations to make the authentication experience more engaging.


### What makes it special?

- 🎨 Custom illustrated characters
- 👀 Interactive animated elements
- 🔐 Fun login experience
- ✨ Modern glassmorphism-inspired UI
- 🎭 Unique visual storytelling
- ⚡ Designed and implemented under hackathon time pressure

Creating a visually interesting animated experience within **just one hour** was the most exciting part of this challenge.
